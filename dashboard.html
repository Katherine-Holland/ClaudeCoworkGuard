Settings

Local policies and protection preferences.

Blocking Rules

Block passwords and personal data

Stops requests containing Social Security Numbers, credit card numbers, passwords, and API keys from reaching AI services. Recommended: keep this on.

Block access tokens and service keys

Stops requests containing login tokens, GitHub access keys, and payment service credentials. May occasionally flag legitimate requests.

Block contact information

Stops requests containing email addresses, phone numbers, and internal network addresses. Not recommended for most users — may block normal requests.

Ask me before blocking

Instead of blocking automatically, CoworkGuard pauses the request and asks you to decide. The AI app will wait up to 60 seconds for your answer.

Quiet mode

Suppress macOS notifications. Events are still logged in Activity.

Proxy Configuration

Network port

The port CoworkGuard uses to monitor your network traffic. Default is 8080 — only change this if something else on your Mac is using that port.

History size

How many events to keep in your activity history. Older events are removed automatically when the limit is reached. Default: 1000.

Folder Access Control

Approved folders

Limit which folders on your Mac AI tools are allowed to read from. Content from any other folder will be blocked before it can be sent to an AI service. Leave empty to allow access to all folders.
