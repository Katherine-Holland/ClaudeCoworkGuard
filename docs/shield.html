Pro

Confirmed correlations, not guesses.

The free version matches events by time window. Pro stamps every event with a verified actor identity — so sequences are evidence, not inference.

Confirmed actor tracking

Every event stamped with bundle ID, PID, and process start time. Correlations become confirmed evidence rather than time-window inferences.

Developer environment protection

Watches .env files, GitHub tokens, SSH keys, and repo secrets. Fires when an AI tool accesses these before the data has a chance to leave.

Full audit export

Export your complete event history as CSV or JSON. Every blocked request, every correlation, every decision — with actor IDs and timestamps.

Shield

AI governance for security teams.

One view across all developer machines. Runtime trust infrastructure for AI-powered organisations.

Org-wide dashboard

Aggregate view across every developer machine — which AI tools are sending the most data, which patterns are triggering, who is doing what — without raw content.

Policy as code

Define blocking rules in a coworkguard.policy.yml file. Check it into your repo. Enforced at the proxy layer on every machine — developers cannot override critical rules.

MCP observability

Full visibility into every tool in an agent's toolchain. Track agent relationships, skill approvals, quarantine events, and tool output scanning across your entire org.
